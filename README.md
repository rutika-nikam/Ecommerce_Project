# E-commerce SQL Project

## About the Project

This project is a SQL-based E-commerce Database designed to manage
and organize information related to products, categories, customers,
and orders.

The project demonstrates how SQL can be used to create database
tables, store data, retrieve information, and perform different
queries for an E-commerce system.

## Technologies Used

- MySQL
- SQL
- MySQL Workbench

## Database Concepts Used

- Database and Tables
- Primary Key
- Foreign Key
- Constraints
- INSERT
- UPDATE
- DELETE
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions
- JOINs
- Subqueries

## Project Features

- Product and category management
- Customer information management
- Order management
- Retrieving product and order information
- Filtering and sorting data
- Performing calculations using aggregate functions
- Combining data from multiple tables using JOINs

## Project Purpose

The main purpose of this project is to practice SQL database
design, data manipulation, and querying techniques by creating
a simple E-commerce database.
